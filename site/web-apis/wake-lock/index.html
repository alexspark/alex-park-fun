  • Grey: off.

    Used on this page

    Links go to MDN. Each line says how this page uses it.

    Wake Lock

    • navigator.wakeLock.request() asks the browser to keep the screen on.
    • WakeLockSentinel is the object that request() gives back. It is your handle to the lock.
    • sentinel.release() turns the lock off.
    • release event fires when the lock turns off, for any reason.

    Page state

    • visibilitychange event fires when you leave or return to the tab. The page uses it to turn the lock on again.
    • document.hidden is true when the tab is not visible.
    • document.title shows the state in the tab title.
    • <link rel="icon"> with an SVG data: URL draws the colored tab icon.

    Checks

    • isSecureContext tells if the page uses HTTPS.
    • Permissions Policy can block the lock in an iframe or with a header.
    • navigator.permissions.query() asks the browser for the permission state.
    • navigator.getBattery() reads the battery level. Only Chrome and Edge have it.

    Sound, saving, copy

    • Web Audio API: an AudioContext, an OscillatorNode and a GainNode make the tones. No sound files.
    • localStorage remembers your settings in this browser.
    • navigator.clipboard.writeText() copies the report.

    JavaScript and CSS

    • JavaScript modules split the code into files.
    • EventTarget and CustomEvent let the lock code tell the page about changes.
    • setInterval() updates the timers each second.
    • :has() styles the selected auto-off button.
    • prefers-reduced-motion stops the pulse if you turn off motion.
